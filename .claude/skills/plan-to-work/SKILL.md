# 研究與實作工作流程規範

標準化 NanoClaw 功能開發流程，確保知識傳承與品質控制。

> **版本**: v1.0  
> **適用**: NanoClaw 所有版本

---

## 1. 工作流程 (三階段)

### Phase 1: 研究評估 (必須)

```
1.1 搜尋新技術資訊
    → websearch 關鍵字 + 官方文檔

1.2 評估候選方案
    → 參數量、準確率、延遲、成本、授權

1.3 確定整合價值
    → 與現有方案的差異點
```

### Phase 2: 架構設計 (必須)

```
2.1 設計整合點
    → 新增/修改哪些檔案

2.2 評估改動範圍
    → Small (< 50 行) / Medium / Large

2.3 制定實作順序
    → 依賴順序排序
```

### Phase 3: 記憶留存 (必須)

```
3.1 撰寫工作日誌
    → Obsidian/Nano_Memories/RESEARCH/

3.2 建立技能檔案
    → .claude/skills/{skill-name}/

3.3 更新 CHANGELOG
    → Obsidian/Nano_Memories/CHANGELOG.md
```

## 3. 迭代記錄規範

每次實作必須記錄：

### 3.1 測試結果記錄

```markdown
### 測試 N: {描述}

**時間**: {YYYY-MM-DD HH:MM}
**結果**: ✅ 成功 / ❌ 失敗 / ⚠️ 部分成功
**輸出**: {關鍵輸出}
**問題**: {如有}
**修復**: {解決方案}
```

### 3.2 實際迭代範例：OCR 整合

```
### 測試 1: 基本環境
**結果**: ❌ 失敗
**問題**: ModuleNotFoundError
**修復**: 使用 anaconda python 路徑

### 測試 2: 參數錯誤
**結果**: ❌ 失敗
**問題**: show_log 參數不存在
**修復**: 移除參數

### 測試 3: 模型下載
**結果**: ⚠️ 部分成功
**問題**: 需要下載多個模型
**修復**: 等待模型下載

### 測試 4: OCR 卡住
**結果**: ❌ 失敗
**問題**: PaddleOCR 在 macOS 環境卡住
**修復**: 暫時擱置，改用 Gemini Vision
```

### 3.3 迭代原則

1. **每次測試 → 記錄結果**
2. **失敗 → 分析原因 → 修復 → 再測試**
3. **無法解決 → 記錄問題 → 選擇替代方案**
4. **完成後 → 更新工作日誌和技能檔案**

### 3.2 迭代更新原則

1. **測試失敗 → 記錄錯誤 → 修復 → 再測試**
2. **每次迭代更新工作日誌**
3. **完成後更新技能檔案**

### 3.3 範例：OCR 整合迭代

```
### 測試 1: 基本環境
**結果**: ❌ 失敗
**問題**: ModuleNotFoundError: No module named 'paddleocr'
**修復**: 使用 anaconda python 路徑

### 測試 2: 參數錯誤
**結果**: ❌ 失敗
**問題**: show_log 參數不存在
**修復**: 移除該參數

### 測試 3: 模型下載
**結果**: ✅ 成功 (需要等待模型下載)
**輸出**: 5719 字元OCR結果
```

## 4. 實際案例：OCR 整合

### 4.1 研究結果

| 方案             | 參數量 | OmniDocBench | 特色     |
| ---------------- | ------ | ------------ | -------- |
| PaddleOCR-VL-1.5 | 0.9B   | 94.5%        | 輕量開源 |
| DeepSeek-OCR2    | 3B MoE | 91.09%       | 多模態   |

### 4.2 程式碼改動

| 檔案                  | 改動                               |
| --------------------- | ---------------------------------- |
| `src/config.ts`       | 新增 `PADDLEOCR_ENABLED`           |
| `src/tools/vision.ts` | 新增 `runPaddleOCR()` + 關鍵字判斷 |

### 4.3 關鍵字列表

