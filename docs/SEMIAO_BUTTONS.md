# SeMeow Bot 快捷按鈕配置

## 🎯 目標
為 SeMeow_NSFW_bot 添加快捷回覆按鈕，提供常用功能的快速訪問。

## 📱 按鈕設計

### 主選單按鈕
```
┌─────────────┬─────────────┐
│  🎨 生圖    │  📱 同步TG  │
├─────────────┼─────────────┤
│  🧠 記憶    │  🔍 搜尋    │
├─────────────┼─────────────┤
│  💭 大腦風暴 │  ⚙️ 設定    │
└─────────────┴─────────────┘
```

### 按鈕功能對應
- **🎨 生圖**: 觸發 `/draw` 指令
- **📱 同步TG**: 同步 Telegram 對話紀錄
- **🧠 記憶**: 查看/更新 Obsidian 記憶
- **🔍 搜尋**: 觸發 NSFW 趨勢搜尋
- **💭 大腦風暴**: 啟動 NSFW 創意工作流
- **⚙️ 設定**: 顯示當前配置

## 🛠️ 實現方式

### 方式 1: Inline Keyboard (推薦)
- 按鈕顯示在訊息下方
- 點擊後觸發 callback query
- 適合功能選單

### 方式 2: Reply Keyboard
- 按鈕取代輸入法鍵盤
- 點擊後發送文字指令
- 適合常用指令
