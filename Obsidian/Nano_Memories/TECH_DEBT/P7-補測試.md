## 優先級排序（依 ROI）

### 1. `tests/unit/model-router.test.ts` 🔴必要
測試項目：
- prefix 匹配（`@gemini`, `@claude`, `@grok` 等觸發正確模型）
- keyword 檢測（圖片/程式碼/翻譯等關鍵字路由）
- fallback chain（主模型失敗→備用模型）
- router state 持久化（save/load `router_state.json`）
- 邊界：空 input、未知 prefix、所有模型都 down

模擬：mock `fetch`（不真打 API），mock `fs`（不真寫檔）

### 2. `tests/unit/host-agent.test.ts` 🔴必要
測試項目：
- SSE 解析：正常 chunk、`[DONE]`、斷行中途截斷、malformed JSON
- tool call loop：收到 tool_calls → 執行 → 回傳結果 → 繼續
- MAX_TOOL_ROUNDS 觸頂後停止
- rateLimitedFetch：正常回應、429 重試（≤ 3 次）、超過後 throw
- message history 截斷（`MAX_HISTORY = 20`）

模擬：mock `fetch`，mock tool executors

### 3. `tests/unit/telegram-markdown.test.ts` 🟡重要
（前置：P6 已抽出 `telegram-markdown.ts`）
測試項目：
- 粗體 `**text**` → `<b>text</b>`
- 斜體 `*text*` → `<i>text</i>`
- code block ````lang\ncode```` → `<pre><code class="language-lang">code</code></pre>`
- inline code → `<code>text</code>`
- 巢狀格式
- 特殊字元 HTML escape（`<`, `>`, `&`）
- 空字串、純文字（無 markdown）

純函式，無需 mock。

### 4. `tests/unit/db.test.ts` 🟡重要
測試項目：
- CRUD：saveMessage / getMessages / getRecentMessages
- session 管理：getSession / updateSession
- scheduled_tasks CRUD
- migration（schema 版本升級）
- concurrent access（兩個 write 不互鎖）

使用 in-memory SQLite（`:memory:`）

### 5. `tests/unit/task-scheduler.test.ts` 🟡重要
測試項目：
- cron 解析（`0 9 * * *` → 正確的 next_run）
- 到期任務偵測
- 任務執行後 next_run 更新
- 一次性 vs 重複任務
- 邊界：過去時間、無效 cron
